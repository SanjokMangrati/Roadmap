# Curriculum

**Start here: [`study-roadmap.md`](study-roadmap.md).** It is the plain-language study plan: every topic, its subtopics, how deep to go, when you're done, what to skip, and a day-by-day schedule.

The other files are detailed working files behind the roadmap. You don't need to read them to study.

| File | What it holds |
|---|---|
| `study-plan.csv` | Every study session with its date, minutes and resource; update the `status` column as you go |
| `company-branches.md` | Each company's interview stages, AI policy and company-specific preparation |
| `rabbit-hole-parking-lot.md` | Topics deliberately left out, and what would bring each back |
| `master-curriculum.md` | Technical detail: priority scoring, hour calculations, exit tests per topic, cut list |
| `coverage-audit.md` | Traceability from each company requirement to the topic that covers it |
| `candidate-assessment.md` | Starting-level estimates (not measured; replaced by your Day 1–2 self-tests) |
