# vidIQ: Senior Frontend Engineer (Remote)

Researched and verified 2026-10-09 (REACH list, lighter pass).

## 1. Summary

- **Role:** Senior Frontend Engineer (Remote). The role is frontend-leaning but expects end-to-end ownership of product surfaces: the UI, the APIs behind it, the data, and production performance. You would also ship LLM-driven features and lead a JavaScript-to-TypeScript refactor. The first-party posting is on vidIQ's Recruitee careers site, published 2026-09-24 and updated 2026-10-02, and is live today (S1).
- **Eligibility: `unverified` (conflicting).** The posting says: "This is a remote position open to candidates worldwide. Employment classification and engagement structure will be determined based on location, legal requirements, and mutual fit." (S1) However, the posting's location list, which also drives the required application question "What is your preferred work location?", contains only Vancouver, Buenos Aires, São Paulo, Mexico, Lima, Lisbon, London and Austin. India is not among them (S1).
- **Pay vs target:** US$80,000–150,000 per year. vidIQ uses "internal equity and geo-location based pay, with the upper range reserved for individuals demonstrating exceptional job knowledge" (S1). India pay would probably sit at or below the bottom of the band (inference). Even US$40K would clear 1.5–2 lakh INR per month, but the actual India figure is unknown. The form asks for "desired compensation in USD (gross amount)".
- **Process:** No stages are published. The application itself is a screening step. It has seven required questions, including two long written answers about your AI-assisted development workflow and a **recorded video answer** on a project you're proud of, covering the technical difficulty and trade-offs (S1). Glassdoor data is thin and old (S3).
- **AI policy:** AI use is **`expected` in the job**: "You'll use tools like Claude Code, Cursor, and GitHub Copilot every day" (S1). The application probes AI workflow in depth. The AI policy for any live interview is `unknown`.
- **Fit: `out of reach` (final on years).** "At least 5 years of professional software development experience" is required; the candidate has about 3. Skill overlap (React, Next.js, TypeScript, Node, AI-assisted coding) is otherwise strong.

- For India: "This is a remote position open to candidates worldwide." Also from the perks: "Work Remotely: Embrace the freedom to choose your ideal workspace anywhere in the world." (S1) Himalayas lists the role as "Open to candidates from all countries" (S2).

The application's required "preferred work location" question is built from that list (S1). This suggests vidIQ has hiring entities or employer-of-record coverage in those countries only (inference).

**Employment type:** Recruitee `fulltime_permanent`, 40 hours a week. The posting says classification "will be determined based on location". There is a monthly communication stipend and flexible time off (S1).

## 5. Stage-by-stage evaluation targets (brief)

- **Written AI answers:** Describe a concrete workflow: which tools, what you delegate, how you review (tests, types, diff reading) and a real failure you caught. Generic answers will likely be screened out (inference).
- **Video answer:** This is a recorded "explain your trade-offs" task, which is exactly the candidate's weak area. Script and rehearse a 2–3 minute story about one project, covering the problem, the hard part, the options considered, why you chose one and what you would change.
- **Likely technical rounds (unverified):** a React/Next.js/TypeScript skills test, plus discussion of LLM streaming UI and API design.

## 6. Competency taxonomy (brief)

- **Frontend:** React, Next.js, TypeScript migration, Vite, Tailwind, state management (Redux/Zustand), browser extensions.
- **Backend:** API design, databases, caching and queues, debugging across client and server.
- **AI:** daily AI-coding workflow, review discipline, LLM product features (streaming, prompts, evals), MCP.
- **Ownership and communication:** roadmap proposals, documentation, mentoring, explaining to non-technical people.
